## Como instalar Mod YandroX
##### Requisitos:
* Microsoft .NET Framework 4.8

##### Como Instalar:
Primero Haz Click en este Enlace de [.NET Framework 4.8](https://dotnet.microsoft.com/es-es/download/dotnet-framework/thank-you/net48-web-installer)

Luego Haz Doble Click en El archivo que se descargo, Y Luego Presiona Continuar Y todo en Siguiente, Y Luego, Al terminar, Ya podras ejecutar YandroX



(Contraseña del .zip: yandrox123)
